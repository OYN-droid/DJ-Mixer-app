# Core Principles

## Play First

Put a successful first sound, first mix, or first pattern close to entry. Default states should be musically useful and safe.

## Grow Naturally

Teach through the workflow. Reveal deeper control when it becomes relevant, while preserving continuity between beginner and advanced use.

## Manual Control Always Exists

Automation never removes the ability to play, stop, edit, override, or perform directly. Manual input is authoritative.

## AI Is Optional

The application remains a complete DJ and production workstation without AI. AI features add leverage, not dependency.

## Progressive Disclosure

Simple Mode shows complete essential workflows. Advanced Mode reveals precision, routing, analysis, automation, and deeper editing.

## Preview Before Apply

Material changes to audio, patterns, arrangements, or project structure require a preview or an explicit instant-apply choice.

## Undo AI Actions

Every applied AI action has a clear recovery path. Undo restores the prior creative state, not an approximation.

## No Placeholder Controls

An enabled control performs its stated action. Unavailable capabilities are disabled, labeled honestly, and accompanied by a useful explanation.

## No Silent Failures

Failures produce visible, actionable feedback. Partial success is distinguished from complete success. Diagnostic detail is available without overwhelming normal use.

## One Source of Truth

Each domain has one canonical state model. Editors, previews, AI plans, playback, persistence, and exports read from or intentionally derive from that model.

## Consistent Interaction Patterns

Play, pause, stop, preview, apply, cancel, save, and undo mean the same thing across workspaces. Selection, focus, active playback, recording, and errors use consistent visual and accessible states.

## Clear Playback Ownership

Every audible source has an owner, visible status, and reliable stop path. Global Stop remains authoritative across the application.

## Preserve the Artist's Work

Replacing, clearing, importing, regenerating, or changing modes must not destroy work without explicit confirmation or recovery.
