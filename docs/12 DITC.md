# DITC

DITC is DeckForge's music discovery and library workspace. Its name reflects the practice of digging in the crates: listening closely, finding connections, and building a collection with personal meaning.

## Library experience

DITC brings local files, project music, saved collections, and authorized connected sources into one discovery surface. It should support fast browsing as well as deliberate research through search, filters, tags, notes, artwork, source, BPM, key, energy, genre, era, and custom collections.

The library distinguishes between a track record and its playable source. A track may have rich metadata but require authorization, relinking, streaming, or local download before it can be loaded. DeckForge should state that capability clearly instead of showing controls that cannot succeed.

## Digging and curation

Auditioning must be quick, non-destructive, and separate from deck playback unless the artist explicitly loads a track. Artists can save discoveries to crates, add project-specific notes, compare candidates, and preserve the path that led to a find.

Recommendations should support purposeful digging. They may identify complementary tracks, samples, influences, tempo neighborhoods, harmonic relationships, or narrative roles. The system should explain the connection and let the artist tune or reject it. Popularity alone is not a sufficient recommendation strategy.

## Project connection

DITC feeds the wider workstation without taking ownership of it. A track can be sent to a deck, included in a Smart Mix plan, referenced by Mixtape Intelligence, or attached to a project. Those actions use stable track identities so tags, cues, and notes remain connected if a file is moved or a provider changes.

Local file relinking should preserve the library record whenever identity can be confirmed. Duplicate detection should offer review before merging records. Source-specific restrictions, account status, and offline availability must remain visible.

DITC succeeds when the artist can move from curiosity to a playable, organized idea without losing context or being surprised by source limitations.
