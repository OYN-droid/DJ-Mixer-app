# Information Architecture

DeckForge is organized by creative intent. Navigation groups features into Play, Create, and Discover while maintaining a persistent global transport and shared project context.

## Play

Play contains performance-first workspaces:

- **Decks**, two-deck playback, mixing, cueing, looping, transitions, and Smart Mix
- **Pads**, samples, banks, scenes, live triggering, chopping, and performance recording
- **Performance**, a focused live view that combines the controls needed for an active set

## Create

Create contains composition and production workspaces:

- **Beat Forge**, kits, grooves, sequencing, finger drumming, rhythm generation, and recording
- **Harmony Lab**, instruments, keyboard performance, chords, bass, melody, composition, and harmony matching
- **Stem Lab**, separation, stem audition, routing, remix preparation, and mashup building
- **Arrangement**, timeline composition, performance clips, automation, and finishing

## Discover

Discover contains research, context, and guided creation:

- **DITC**, music library organization, search, collections, tags, and matching
- **Connected Sources**, capability-aware access to local and authorized providers
- **Mixtape Analyzer**, reference analysis, sequencing insight, themes, callbacks, and energy
- **AI**, project-aware recommendations and plan review
- **Producer Studio**, creative missions, recommendations, and project direction
- **Prompt Studio**, saved prompts, reusable instructions, previews, and histories

## Cross-cutting layers

The Global Transport, Project Intelligence, playback registry, undo history, recording, persistence, and diagnostics are application layers, not destinations. They follow the user across workspaces.

Each asset has a stable identity and provenance. A track, pad, beat pattern, harmony pattern, stem, or arrangement clip should retain its source, timing, tags, and project relationship when moved.
