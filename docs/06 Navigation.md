# Navigation

Navigation follows creative intent and preserves continuity. Changing pages does not implicitly discard state or hide active playback ownership.

## Simple Mode

Simple Mode presents the shortest complete workflow for the current workspace. It includes the controls required to begin, play, stop, save, and recover. It does not present decorative controls or incomplete advanced concepts.

Simple Mode is not a demo. It uses the same canonical project and playback models as Advanced Mode.

## Advanced Mode

Advanced Mode reveals precision editing, analysis, routing, modulation, automation, diagnostics, and deeper project integration. Switching modes preserves all settings and work.

## Progressive disclosure

Reveal complexity through:

- Workspace mode selection
- Expandable inspectors and diagnostics
- Contextual actions for selected items
- Preview panels before material changes
- Clear pathways from starter actions to deeper editing

## Keyboard shortcuts

Shortcuts must be discoverable, scoped, and safe around text input. Global shortcuts should remain small in number and consistent. Performance shortcuts activate only in the relevant workspace. Shortcut labels appear on playable keys and pads.

## Transport behavior

Each sound-producing workspace has local transport that affects only that owner. The persistent Global Transport shows active sources and controls application-wide playback. Global Stop All Audio always remains available.

Navigation does not create a second scheduler or duplicate playback. If audio continues across pages, its owner remains visible through global status and navigation indicators. If a workflow requires stop-on-navigation, that policy is explicit and documented for that source.
