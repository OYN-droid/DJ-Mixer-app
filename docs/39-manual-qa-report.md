## Scope and result language

This report applies every row in `docs/08-manual-qa-checklist.md` to the current build. `Pass` means the browser performed the stated operation and an observable state or real output verified it. `Partial` means only part of a compound checklist row was exercised. `Manual required` means the result depends on listening, operating-system permission UI, physical drag and drop, or assistive technology that headless automation cannot verify. It is not counted as a pass.
