# DJ Workflow

The primary DJ workflow moves from discovery to performance without requiring the user to leave the project context.

## 1. Import

Add local music or connect an authorized source. Import preserves filename, available metadata, provenance, and playability. Unsupported or preview-only sources clearly state their capabilities.

## 2. Organize in DITC

Search, tag, favorite, group, analyze, and annotate tracks. Build collections around a set, theme, event, energy arc, or creative idea. Project Match and Transition Match may suggest useful relationships without changing the collection.

## 3. Load a deck

Drag or send a playable source to Deck A or Deck B. The deck shows readiness, analysis confidence, timing, selection, loop state, and playback ownership.

## 4. Mix manually

Cue, play, pause, seek, loop, adjust channel level, shape the filter, and move the crossfader. Manual control is always authoritative. Quick transitions assist without replacing the basic deck workflow.

## 5. Use Smart Mix when useful

Choose sources and intent, inspect the plan, review tempo safety, then execute. Prompt-directed transitions describe musical goals. Manual movement cancels or revises automation safely.

## 6. Perform

Use pads, stems, scratches, effects, Beat Forge, or Harmony Lab as supporting layers. Each source remains independently stoppable and globally visible.

## 7. Record

Capture the master performance and, where appropriate, structured performance events. Recording status remains visible and Global Stop handles recording cleanup.

## 8. Export

Export the recorded mix with project metadata, notes, and a recoverable project state. Export never claims provider content rights that the user does not hold.
