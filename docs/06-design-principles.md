# Design principles

1. **Play First.** Put a successful first sound and first mix close to the start.
2. **Grow With the User.** Reveal depth as skills and ambition grow.
3. **Manual Control Is Always Available.** Automation must not take control away.
4. **AI Is Optional and Contextual.** Offer assistance where it is useful and explain what it will change.
5. **Progressive Disclosure.** Keep the first workflow focused while preserving advanced capability.
6. **No Placeholder Controls.** A visible active control should perform its stated action.
7. **Preview Before Apply.** Let users hear or inspect important changes first.
8. **Undo AI Actions.** AI-driven changes need a clear return path.
9. **Clear Playback Ownership.** Users should know what is making sound and how to stop it.
10. **Accessible, Fun, and Tactile Interaction.** Support keyboard, pointer and assistive technology without losing physical character.
