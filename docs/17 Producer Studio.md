# Producer Studio

Producer Studio is the project-level creation and arrangement workspace. It brings rhythm, harmony, samples, stems, recordings, and references into a coherent composition without replacing the specialized tools that created them.

## Project canvas

The studio presents an arrangement of tracks, clips, regions, markers, automation, and versions. Material from Beat Forge, Harmony Lab, Pads, Stem Lab, decks, and recordings arrives with its identity and editability intact. Source changes can be reflected through explicit update choices rather than silently altering an arrangement.

The artist can move from a sketch to a structured song, remix, edit, or performance set. Essential operations include recording, trimming, duplication, looping, grouping, muting, soloing, routing, automation, versioning, and export. Complexity appears progressively so that a first arrangement does not require understanding the entire mixer.

## Prompt Studio and missions

Prompt Studio translates creative direction into inspectable project proposals. A request may suggest an arrangement outline, alternate section, instrumentation change, transition, or production task. It should identify the project objects it will affect and offer a preview or candidate version before application.

Missions turn broad goals into optional, achievable steps such as building an eight-bar foundation, recording a variation, or resolving an overcrowded section. They adapt to project state and explain why a step might help. They are guidance, not gates, and can be dismissed or rewritten.

## Recommendations and versions

Project Intelligence may surface focused recommendations based on the current arrangement, references, and artist intent. Accepted changes become ordinary editable material. Rejected advice should not repeatedly interrupt the workflow.

Meaningful experiments should be easy to preserve as versions. Undo protects immediate edits, while named versions protect creative directions and export milestones. Recording and rendering use the shared audio architecture so the heard mix matches the captured result.

Producer Studio succeeds when every DeckForge idea can become an organized, revisable, and exportable work without losing its creative history.
